# SumoController 项目开发计划

## 1. 项目概述
SumoController 是一个可模块化的集控小工具，包含运行在 Windows 上的高权限客户端，以及运行在 Linux（或其他环境）上的集控服务端。客户端采用动态插件架构，通过拉取服务端的组件及配置实现自动化网络控制、行为限制与日志监控。

## 2. 技术栈选型
- **客户端主程序 (SumoController)**：C# / .NET 8
  - 构建目标：`PublishSingleFile`（独立 exe），配合代码裁剪（Trim）以保持小巧。
  - 核心能力：UAC 自动提权、计划任务注册、文件下载、动态反射加载程序集。
- **客户端组件 (Plugins)**：C# / .NET 8 类库
  - 分发格式：编译为 `.dll` 后重命名为 `.cipx` 以插件形式分发。
- **服务端 (Server)**：Python 3
  - 推荐框架：FastAPI（轻量、高性能、自带接口文档）。
  - 核心能力：提供静态文件（`.cipx` 插件及 `config.yml`）下载服务、接收并持久化客户端日志数据。
- **代码管理**：单体仓库 (Monorepo) 管理。

```text
SumoController/
├── docs/                   # 项目文档目录
│   └── 项目计划.md         # 本文档
├── Client/                 # Windows 客户端目录 (C# .NET 8)
│   ├── Sumo.Core/          # 核心接口库 (定义 IPlugin 等公共契约)
│   ├── SumoController/     # 主程序基座 (负责提权、下载更新、加载插件)
│   └── Plugins/            # 插件源码目录
│       ├── AutoWLAN/       # 自动连接指定 Wi-Fi
│       ├── AntiEdgeSurf/   # 自动关闭 edge://surf 窗口
│       ├── BoxLogger/      # 记录窗口焦点变化及进程信息
│       ├── AntiBluetooth/  # 自动关闭蓝牙
│       ├── AntiLine/       # 禁用有线网络
│       └── VerifyWLANMac/  # Wi-Fi MAC 地址白名单验证
├── Server/                 # Linux 服务端目录 (Python)

│   ├── requirements.txt    # Python 依赖清单

│   └── data/               # 存放接收到的 BoxLogger 日志
└── 提示词.md               # 原始需求与思路草稿
```

## 4. 开发阶段规划

### 阶段一：核心架构与服务端基建 (Core & Server)
1. **定义公共契约 (Sumo.Core)**
   - 编写 `IPlugin` 接口，定义 `Name`, `Version`, `Start()`, `Stop()` 等生命周期方法。
2. **服务端搭建 (Server)**
   - 使用 FastAPI 初始化 Python 服务端。
   - 编写静态文件路由，供客户端下载配置文件和插件。
   - 编写日志接收 API（`POST /api/logs`）。
3. **主程序基座开发 (SumoController)**
   - **权限模块**：实现无管理员权限时自动 UAC 提权重启。
   - **自启模块**：检查并创建 Windows 计划任务实现开机自启。
   - **更新模块**：启动时请求服务端，下载/更新 `config.yml` 和 `plugins/` 目录下的 `.cipx` 文件。
   - **引擎模块**：通过 `Assembly.Load` 动态加载 `.cipx` 插件并启动。

### 阶段二：系统限制类组件开发 (Restrictions)
1. **AntiEdgeSurf**：封装 Win32 API (`EnumWindows` 等)，低频扫描并关闭标题匹配 `edge://surf` 的窗口。
2. **AntiBluetooth**：通过 PowerShell / WMI 禁用蓝牙无线电或设备。
3. **AntiLine**：扫描系统网络适配器，识别有线网卡（Ethernet）并将其禁用。

### 阶段三：网络控制类组件开发 (Network)
1. **AutoWLAN**：利用 `ManagedWifi` 或原生 Native WiFi API，读取本组件配置并自动连接指定 SSID。
2. **VerifyWLANMac**：监听网络连接事件，比对当前连接 BSSID 与配置中的白名单，非法则强制断连。

### 阶段四：监控组件开发 (Monitoring)
1. **BoxLogger**：
   - 监听或轮询（低频）前台窗口焦点变化 (`GetForegroundWindow`)。
   - 记录时间、窗口标题、主程序可执行文件路径。
   - 实现本地缓存（防丢失）和定时异步 HTTP 上传至服务端。

## 5. 编译与部署策略
- **客户端构建**：使用 `dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true` 命令一键构建无依赖 exe。
- **插件构建**：各组件独立编译为 dll，通过脚本自动重命名为 `.cipx` 并拷贝到 Server 的 static 目录下。
- **服务端部署**：在 Linux 服务器上使用 `uvicorn main:app --host 0.0.0.0 --port 8000` 运行，可结合 `systemd` 守护进程或 Docker 部署。
